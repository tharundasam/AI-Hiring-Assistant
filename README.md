# AI Hiring Assistant

## Features
- Resume Upload
- Job Description Upload
- Resume Parsing
- ATS Score
- Semantic Ranking
- AI Summary
- Interview Question Generator
- Recruiter Chat
- Recruiter Dashboard
- PostgreSQL Database

## Tech Stack
- FastAPI
- Streamlit
- PostgreSQL
- SQLAlchemy
- Sentence Transformers
- FAISS
- Hugging Face
- spaCy
- Plotly

## Installation

pip install -r requirements.txt

uvicorn app:app --reload

streamlit run app.py
